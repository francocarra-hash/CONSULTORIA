# Boton

Botones de la tienda: principal, secundario y de WhatsApp. Todos miden `boton-alto` de alto como mínimo, usan el estilo `boton` y se redondean con `radius-md`.

| Variante | Uso | Colores |
|---|---|---|
| Principal | Comprar, Agregar al carrito, Ver productos | `verde-accion` con texto `sobre-accion`; hover `verde-accion-hover` |
| Secundario | Ver más, Ver ficha técnica | Borde y texto `verde-accion`; hover con fondo `verde-claro` |
| WhatsApp | Consultar por WhatsApp | `whatsapp` con texto `texto` |

- Poné un solo botón principal por bloque.
- El texto dice la acción exacta: "Comprar", no "Ver más" ni "Click acá".
- No uses `naranja` ni `verde` para botones: no tienen contraste suficiente con texto blanco.
