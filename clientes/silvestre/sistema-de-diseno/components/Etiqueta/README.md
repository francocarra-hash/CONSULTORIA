# Etiqueta

Etiquetas chicas sobre la foto de producto, arriba a la izquierda, con estilo `etiqueta` y `radius-sm`.

| Etiqueta | Colores |
|---|---|
| Oferta o "% OFF" | `naranja` con `texto` |
| Envío gratis | `verde-claro` con `verde-accion-hover` |
| A batería, nafta o eléctrico | `superficie` con `texto` |

- Poné como máximo dos etiquetas por producto.
- No inventes etiquetas nuevas de color: si hace falta otra, usá la de `superficie`.
